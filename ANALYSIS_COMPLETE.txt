ROOT CAUSE (100% IDENTIFIED):
─────────────────────────────

Vercel cannot invoke dist/server/server.js correctly because:
  
  1. vercel.json points to: serverless.default → dist/server/server.js
  
  2. Vercel expects: A handler function it can call
  
  3. server.js exports: { server as default } with .fetch() method
     (Not directly callable by Vercel's runtime)
  
  4. Result: Requests don't reach TanStack Start router
  
  5. Outcome: 404 NOT_FOUND on ALL routes


THE SOLUTION (VERIFIED):
────────────────────────

Create 2-line bridge file that Vercel understands:

  FILE: api/handler.js
  ────────────────────
  import { server } from '../dist/server/server.js';
  export default async function handler(request) {
    return await server.fetch(request);
  }

Update configuration:

  FILE: vercel.json
  ─────────────────
  {
    "version": 2,
    "buildCommand": "npm run build"
  }

Deploy:

  git add api/handler.js vercel.json
  git commit -m "fix: add Vercel API handler for TanStack Start"
  git push origin main
